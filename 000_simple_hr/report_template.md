# Лабораторная работа №0. Пример простейшей задачи на КОРСАР

## 1. Цель работы
Получить значение квазистатического расхода воды через участок трубы с установленным дросселем и заданным перепадом давления
---
## 2. Описание постановки задачи
В задаче моделируется течение через участок трубы DN25 длиной 1м, с установленным по середине участка дросселем.  
Параметры задачи представлены в таблице
|Параметр|Значение|
---|:---:|
|Температура потока |20°C|
|Давление на входе |1.1 МПа|
|Давление на выходе  |1.0 МПа|
|КГС $\xi$ дросселя  |7.|
|Длина и диаметр DN трубы, м   |1, 0.025|
---
## 3. Требуемые результаты
- Вывести графики давления до дросселя и расхода через дроссель
- Определить значение установившегося расхода и сравнить его с теоретическим значнеием по формуле Дарси

## 5. Получение результатов работы
Для получения результатов необходимо:  
- выполнить запуск кода КОРСАР при помощи команды 
```cmd
START.bat task result
```
- после окончания расчета выполнить процессинг бинарного фалйа результатов расчета _korres_ при помощи команды  
```cmd
PROC.bat task result
```
- выполнить обработку результатов расчета при помощи запуска [python-файла](./task/plot_sensor.py) или [Jupyter Notebook](./task/plot_sensor.ipynb)
