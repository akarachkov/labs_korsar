# Лабораторная работа №3. Автоматическое регулирование расхода через потребитель 

## 1. Цель работы
Целью работы является сборка схемы автоматического регулирования расхода через потребитель за счет применения дроссельно-питательной связки клапанов

## 2. Описание постановки задачи
В задаче моделируется система регулирования расхода среды через потребитель. Для обеспечения линейной регулировочной характеристики может быть применена связка из двух клапанов, один из которых (питательный, ПК) имеет линейную пропускную характеристику, а второй (дроссельный, ДК) предназначен для поддержания заданного перепада давления на первом. В этом случае расход через потребитель будет линейно прямо пропорционален положению РО питательного клапана, что может служить основой для создания простой и надежной системы регулирования расхода. Нодализация расчетного варианта представлена на рисунке ниже
![](./pic/nodal.png "нодализация варианта")  
Изменение давлений на входе и выходе а также сопротивления потребителя (вследствие неопределенных связей и причин) может вызвать колебания расхода через него, что может быть скомпенсировано путем оперативного возвращения перепада давления на ПК путем корректировки положения ДК. Алгоритм, управляющий перемещением ДК и, как следствие, перепадом на ПК может быть реализован в виде ПИД-звена, подбор коэффициентов которого должен производиться на основе наиболее вероятных динамических характеристик возникающих отклонений параметров. Для реализации данного алгоритма в расчетной схеме может быть задействован элемент CONT кода КОРСАР, оптимальные значения коэффициентов которого могут быть подобраны для минимизации выбегов расхода при регулировании и для наиболее точного и быстрого регулирования.
Очевидно, что для обеспечения поддержания перепада давления на ПК необходимо превышение быстродействия РО ДК над максимальной скоростью изменения положения РО ПК (необходимой максимальной скоростью изменения расхода).

## 3. Требуемые результаты
- Определить расходную характеристику РК в абсолютном и относительном виде ($q=f(s)$), сравнить с пропускной для двух вариантов расчета: с полностью открытым ДК и с ДК, находящимся в режиме поддержания перепада на ПК. Определение расходной характеристики произвести путем изменения положения рабочего органа РК и регистрации соответствующего расхода, протекающего через РК и дальнейшей нормировки (при необходимости).
- Подобрать коэффициенты ПИД-регулятора для достижения необходимой точности регулирования 5%, если точность оценивается максимальным отклонением относительного расхода от кривой относительного положения РО ПК в ходе изменения его положения.

## 4. Формат отчетности
В отчетность по лабораторной работе входит:
- файлы зоны задания kordat и kutdat
- отчет в **электронном виде** (формат произвольный), содержащий:
  - постановку задачи
  - нодализацию расчетного варианта
  - графики пропускной и расходной характеристик РК (в относительных единицах) в одних осях 
  - графики положения РО ПК и относительного расхода при максимальной скорости изменения положения РО ПК от 2% до 100%
