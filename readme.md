# Шаблон репозитория для выполнения лабораторных работ по коду КОРСАР

## Структура репозитория
- Лабораторные работы собраны в директориях корня репозитория
- Пример выполнения элементарной лабораторной работы лежит в директории [./000_simple_hr](./000_simple_hr)  
- Для удобства верстки текстового файла зоны задания можно воспользоваться редактором [Notepad++](https://notepad-plus-plus.org) и файлом разметки синтаксиса [KORSAR_v2.XML](./KORSAR_v2.XML) из корня репзитория  
- Для написания и отладки файлов обработчиков результатов на python/Jupyter Notebook, а также верстки отчетной документации в формате markdown рекомендуется пользоваться IDE [Visual Studio Code](https://code.visualstudio.com/) с установленными расширениями  
- Работу с запуском расчета/обработкой результатов проще всего организовать при помощи файлового браузера [Total Commander](https://www.ghisler.com/)  
- В репозиторий **не должны** попадать результаты расчета. Все результаты получаются путем запуска расчета на локальном ПК и сравнения результатов с данными, представленными в отчете по лабораторной работе  

## Порядок работы  
- зарегистрироваться на [github.com](https://github.com/)  
- сделать форк текущего репозитория  
- сделать локальную копию репозитория на своем ПК  
- выполнить лабораторную работу согласно заданию преподавателя  
- запушить в удаленный репозиторий финальную версию, пометить ее тегом **final**  
- выслать преподавателю ссылку на свой форк для проверки
